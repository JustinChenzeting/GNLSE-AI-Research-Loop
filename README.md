# GNLSE AI Research Loop

We study which input pulses best preserve their shape in multimode optical fibers. We built a Python research loop that tests pulse settings with a Julia solver for the generalized nonlinear Schrödinger equation (GNLSE), records each simulation, and compares AI-guided search with classical gradient descent.

Thank you to Prof. Rivera, Fadi, and Dr. Kim. Our simulations use Prof. Rivera’s [FastDifferentiableMMNLO](https://github.com/nrivera494/FastDifferentiableMMNLO) code.
